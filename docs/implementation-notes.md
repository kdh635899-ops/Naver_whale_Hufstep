## 피그마와 달라진 점 (명세 우선)

1. 메뉴 5개: 종정시 입력 → 학사현황 → **평가일정(신규)** → 학점계산 → 마이페이지.
2. 평가일정: 2026-10-25 결정으로 명세 §3.6의 ‘두 열 과목 타일’을 **월~금 시간표**로 대체(`HUFStep_Timetable_Memo_Light.html`은 동작 참고만, 디자인은 기존 토큰 유지). 수업 시간은 학생이 직접 입력(한 과목 여러 개, 월~금만), 시간 없는 과목은 시간표 아래 기존 타일 목록. 상세 패널에서 자유 메모(`메모 저장`)와 시험 정보(`시험 정보 수정`)를 따로 저장. 메모 속 날짜는 알림을 만들지 않음.
3. 피그마의 예시 이름(“김웨이”)·학번·학점·평점·졸업일은 기본값으로 쓰지 않았습니다. 이름(닉네임)은 개인정보 입력에서 선택으로 받아 이 브라우저에만 저장하고, 마이페이지 인사말에 씁니다(비워 두면 “안녕하세요”만 나옵니다).
4. ‘성적 자동 연동’ 문구 대신 학생의 직접 복사·붙여넣기, 입력란 아래 `종정시 열기` 링크.
5. 학점계산의 학년 탭 대신 실제 `학년도+학기` 단위로 표시 (편입생 학년 불일치 방지).
6. 재입력 시 수동 과목·평가 메모를 지우지 않고 병합 확인 절차를 거칩니다.
7. 학사현황에 지원 범위 안내를 한 번만 표시하고, 내 과목 목록과 `과목 추가·수정` 진입점을 추가했습니다 (명세 §3.5).

## 주요 구현 선택

- 스택: 기존 코드가 없어 명세 권장대로 TypeScript + React + Vite. 검증은 zod 하나만 추가.
- 상태 저장: 앱 상태 한 덩어리를 IndexedDB 한 키에 저장 (원자적 저장·migration 단순). 서비스 워커 쓰기(발송 이력)는 다른 키로 분리해 서로 덮어쓰지 않게 했습니다. ponytail: 과목 수천 개 규모까지는 충분, 그 이상이면 객체 스토어 분리.
- 규칙 묶음에 명세 인터페이스에 없는 `scope`(common/program/primary/secondary)와 `allowCourseReuseAcrossGroups`를 추가: §5.2의 “의미별 결합”과 “중복 사용은 규칙으로 결정”을 표현하기 위해서입니다.
- 졸업시험·인증과 공통요건의 ‘통과 확인’은 학생 확인 체크(`certConfirmations`)로만 표시하고 공식 판정처럼 보이지 않게 했습니다.
- 학생이 ‘필수’로 표시한 과목은 공식 매칭과 분리해 표시하며 학점을 따로 만들지 않습니다.
- 주전공 평점은 `primary` 영역 과목 기준입니다 (학교 공식 전공평점 산정 범위는 미확인).
- 데모 모드는 메모리에서만 동작하고 IndexedDB에 쓰지 않으며 알림을 예약하지 않습니다.
- 알림 권한은 설치 시 권한(`notifications`)으로 두고, 실제 발송은 앱 안의 별도 동의 + 켜기 설정으로 제어합니다 (선택적 권한 흐름은 미적용).
